\# 💱 Currency Bot



Телеграм-бот курсов валют на Python (pyTelegramBotAPI).



\## Возможности

\- Курсы валют ЦБ РФ с изменением за сутки

\- Конвертер: `100 USD в RUB` (понимает запятые, лишние пробелы и разные формулировки)

\- Инлайн-кнопки для быстрого просмотра курсов

\- Кеширование данных API (10 минут)



\## Как запустить

1\. Установи зависимости: `pip install -r requirements.txt`

2\. Создай файл `.env` в папке проекта и добавь туда:  

&#x20;  `TELEGRAM\_BOT\_TOKEN=твой\_токен`

3\. Запусти: `python bot\_currency.py`



⚠️ Токен не хранится в коде — он берётся из `.env`, поэтому безопасен при публикации на GitHub.
